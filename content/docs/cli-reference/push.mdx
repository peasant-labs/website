## NAME

`peasant push` — Push ingested transcripts to the Peasant village

## SYNOPSIS

```bash
peasant push [flags]
```

## DESCRIPTION

Pushes locally ingested session transcripts to a remote Peasant village. This allows you to share session data or maintain a remote backup of your analytics.

By default, pushed transcripts are private. Use `--visibility` to control access.

<Callout type="warn">
This command sends session data to a remote service. Review what will be pushed with `--dry-run` before your first push.
</Callout>

## FLAGS

| Flag | Type | Description |
|---|---|---|
| `--dry-run` | bool | Show what would be pushed without sending any data. |
| `--by-source` | bool | Organize pushed data by source provider. |
| `--visibility <level>` | string | Set the visibility of pushed transcripts. Values: `private`, `public`. Defaults to `private`. |

## EXAMPLES

Preview what will be pushed:

```bash
peasant push --dry-run
```

Push all ingested transcripts privately:

```bash
peasant push
```

Push with public visibility:

```bash
peasant push --visibility public
```

Push organized by source provider:

```bash
peasant push --by-source
```

Combine flags for a dry-run of a public, by-source push:

```bash
peasant push --dry-run --by-source --visibility public
```
