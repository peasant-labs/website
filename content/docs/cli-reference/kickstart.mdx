## NAME

`peasant kickstart` — Run the first-time setup wizard

## SYNOPSIS

```bash
peasant kickstart
```

## DESCRIPTION

Runs an interactive setup wizard that prepares Peasant for first use on your machine. The wizard handles:

- **Config file creation** — Generates `~/.config/peasant/config.yaml` with default settings.
- **Provider detection** — Scans your system for supported AI coding assistants (Claude Code, OpenCode) and configures their session paths.
- **Database initialization** — Creates the SQLite database at `~/.local/share/peasant/peasant.db` and applies the current schema.

This command is idempotent — running it again will not overwrite existing configuration without confirmation.

<Callout type="tip">
Run this once after installation. After kickstart completes, you are ready to run `peasant ingest`.
</Callout>

## EXAMPLES

Run the setup wizard:

```bash
peasant kickstart
```

A typical first-time workflow:

```bash
peasant version      # Verify installation
peasant kickstart    # Run setup wizard
peasant ingest       # Ingest your first sessions
peasant web start    # View the dashboard
```
