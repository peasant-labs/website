## NAME

`peasant tui` — Launch the terminal UI

## SYNOPSIS

```bash
peasant tui
```

## DESCRIPTION

Opens an interactive terminal-based user interface for browsing ingested sessions, viewing metrics, and navigating your AI coding assistant analytics — all without leaving the terminal.

The TUI reads from the same SQLite database populated by `peasant ingest`. You must run ingestion at least once before the TUI has data to display.

<Callout type="tip">
The TUI is ideal for quick lookups and keyboard-driven navigation. For richer visualizations, use `peasant web start` to launch the web dashboard instead.
</Callout>

## EXAMPLES

Launch the TUI:

```bash
peasant tui
```

Ingest fresh data and then open the TUI:

```bash
peasant ingest && peasant tui
```
