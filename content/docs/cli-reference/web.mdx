## NAME

`peasant web` — Manage the web dashboard server

## SYNOPSIS

```bash
peasant web start [flags]
peasant web stop
```

## DESCRIPTION

The `web start` command launches a local Next.js web dashboard that serves visual analytics for your ingested sessions. By default it runs on port 8690 and opens your browser automatically.

The `web stop` command stops a running dashboard server.

The web dashboard reads from the same SQLite database populated by `peasant ingest`. You must run ingestion at least once before the dashboard has data to display.

## SUBCOMMANDS

### `peasant web start`

Start the web dashboard server.

### `peasant web stop`

Stop a running web dashboard server.

## FLAGS (start)

| Flag | Type | Description |
|---|---|---|
| `--port <n>` | int | Port to serve the dashboard on. Default: `8690`. |
| `--foreground` | bool | Run the server in the foreground instead of daemonizing. |
| `--no-browser` | bool | Do not automatically open the browser on startup. |
| `--dev` | bool | Run in development mode with hot reloading. |
| `--mock-data-store <sections>` | string | Use mock data for the specified dashboard sections (for development/testing). |

## EXAMPLES

Start the dashboard with default settings:

```bash
peasant web start
```

The dashboard is now available at [http://localhost:8690](http://localhost:8690).

Start on a custom port without opening the browser:

```bash
peasant web start --port 3000 --no-browser
```

Run in the foreground (useful for debugging):

```bash
peasant web start --foreground
```

Run in development mode:

```bash
peasant web start --dev
```

Stop a running dashboard:

```bash
peasant web stop
```

<Callout type="info">
The dashboard server runs as a background daemon by default. Use `--foreground` to keep it in the current terminal session, or `peasant web stop` to shut down the daemon.
</Callout>
